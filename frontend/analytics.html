HOW TO READ THIS PAGE

Evidence, with boundaries

  • The 12 scenarios are synthetic; there are no listener relevance labels or real session logs.
  • Random uses 30 fixed seeds per scenario. Its repeated runs are not 30 independent users.
  • Artist metadata is missing for part of the merged catalogue, so artist metrics report coverage separately.
  • The merged catalogue does not retain the original input source for each track.
  • Fixed-pool quality proxies and full-catalogue timing answer different questions.
  • The source results and checksums remain in evaluation/v2/; this page publishes a compact verified snapshot.
